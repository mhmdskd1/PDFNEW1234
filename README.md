# 🧾 نظام إدارة الفواتير الشامل

نظام ويب متقدم لإدارة الفواتير والمالية مصمم خصيصاً للسوق الهولندي مع دعم كامل للغة العربية.

## 🌟 المميزات الرئيسية

### 📊 لوحة تحكم تفاعلية
- إحصائيات مالية فورية
- مؤشرات الأداء الرئيسية
- وصول سريع للوظائف الأساسية
- آخر 10 فواتير تم إنشاؤها

### 👥 إدارة العملاء
- إضافة وإدارة الوسطاء والممولين
- تتبع تفاصيل العملاء الكاملة
- تعديل ومسح بيانات العملاء

### 🏢 إدارة الشركات
- الشركات المستلمة للفواتير
- شركات الدفع (البنوك)
- التحقق من صحة BTW و KVK للشركات الهولندية
- دعم الشركات غير الهولندية

### 📄 إنشاء الفواتير

#### فواتير PDF متقدمة
- **6 قوالب جاهزة** باللغة الهولندية
- **معاينة مباشرة** قبل التصدير
- **محرر السحب والإفلات** لتخصيص القوالب
- **رفع وتعديل شعارات الشركات**
- **ترقيم تلقائي** للفواتير حسب الشركة الدافعة
- **حفظ سريع** للوسطاء والشركات

#### الفواتير الرقمية
- إنشاء فواتير رقمية سريعة
- **حساب العمولات التلقائي**:
  - الوسيط الرئيسي
  - نصيبنا من الأرباح
  - وسطاء إضافيين (متعددين)
- **3 أنواع من الإعدادات**:
  - 21% - 9% (تحديد يدوي للنسب)
  - 0% (بدون أرباح)
  - فيرلخت (تقسيم يدوي مخصص)

### 💰 النظام المالي المتقدم

#### إدارة المدفوعات
- معالجة الدفعات الكاملة والجزئية
- تتبع حالة الفواتير (غير مدفوعة، جزئية، مكتملة)
- **تصفير الأرصدة وتوزيع الكاش**
- تحويل تلقائي للعمولات عند اكتمال الدفع

#### إدارة الأرصدة
- **صندوقي**: تتبع حركات النقد
- **أرصدة الوسطاء والممولين**: حسابات منفصلة لكل وسيط
- تقارير مفصلة لجميع المعاملات
- فلترة متقدمة للحركات المالية

### 📚 نظام الأرشفة

#### سجل الفواتير PDF
- أرشفة شاملة لجميع الفواتير المدفوعة
- **بحث متقدم** بعدة معايير
- **تصدير وطباعة** الفواتير
- **فلاتر ذكية** للبحث السريع

#### سجل الفواتير الرقمية
- عرض تفصيلي للفواتير الرقمية
- **تفاصيل العمولات الكاملة**
- حساب النسب والمبالغ تلقائياً
- تتبع جميع الوسطاء والأرباح

### 📈 نظام التقارير الشامل
- **كشف الفواتير غير المدفوعة** حسب العملاء
- **كشوفات خاصة** بعميل أو وسيط أو شركة محددة
- **تقرير الأرباح الشامل**
- **تصدير Excel و PDF**
- إحصائيات مالية تفصيلية

### ⚙️ الإعدادات المتقدمة

#### إدارة المستخدمين
- **3 مستويات من الصلاحيات**:
  - مدير عام (صلاحيات كاملة)

#### النسخ الاحتياطي

## 🛠️ التقنيات المستخدمة

- **ExcelJS** - إنشاء ملفات Excel

## 📦 التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js (الإصدار 16 أو أحدث)
- MongoDB (الإصدار 5 أو أحدث)
- npm أو yarn

### 1. استنساخ المشروع
```bash
git clone https://github.com/your-username/invoice-management-system.git
cd invoice-management-system
```

### 2. تثبيت تبعيات الباك إند
```bash
cd backend
npm install
```

### 3. إعداد متغيرات البيئة للباك إند
أنشئ ملف `.env` في مجلد `backend`:
```env
# قاعدة البيانات
MONGODB_URI=mongodb://localhost:27017/invoice_management

# مفتاح JWT
JWT_SECRET=your-super-secret-jwt-key-here
JWT_EXPIRE=7d

# إعدادات الخادم
PORT=5000
NODE_ENV=development

# إعدادات الإيميل (اختيارية)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password

# إعدادات BTW API (مجانية)
BTW_API_URL=https://api.btw-nummer.nl

# إعدادات KVK API (مدفوعة)
KVK_API_KEY=your-kvk-api-key
KVK_API_URL=https://api.kvk.nl/api/v1

# مجلد رفع الملفات
UPLOAD_PATH=./uploads
MAX_FILE_SIZE=10485760
```

### 4. تشغيل الباك إند
```bash
# وضع التطوير
npm run dev

# أو وضع الإنتاج
npm start
```

### 5. تثبيت تبعيات الفرونت إند
```bash
cd ../frontend
npm install
```

### 6. إعداد متغيرات البيئة للفرونت إند
أنشئ ملف `.env` في مجلد `frontend`:
```env
REACT_APP_API_URL=http://localhost:5000/api
REACT_APP_APP_NAME=نظام إدارة الفواتير
REACT_APP_VERSION=1.0.0
```

### 7. تشغيل الفرونت إند
```bash
npm start
```

## 🆘 استكشاف الأخطاء

### مشاكل شائعة

#### 1. خطأ في الاتصال بقاعدة البيانات
```bash
# تأكد من تشغيل MongoDB
sudo systemctl start mongod

# أو باستخدام Docker
docker run -d -p 27017:27017 mongo:latest
```

#### 2. خطأ في تحميل الصفحة
- تأكد من تشغيل الباك إند على المنفذ 5000
- تحقق من متغيرات البيئة
- راجع console الخاص بالمتصفح

#### 3. مشاكل رفع الملفات
- تأكد من وجود مجلد `uploads`
- تحقق من صلاحيات الكتابة
- راجع حد حجم الملف

### سجلات النظام
يتم حفظ السجلات في:
- `backend/logs/error.log` - أخطاء النظام
- `backend/logs/combined.log` - جميع العمليات
